> 이 문서는 몽중다로의 **최상위 근간 문서**입니다. 서비스가 무엇이고 왜 존재하는지에 대한 전체 그림을 담습니다.

## 1. 한 줄 소개

몽중다로는 사용자가 꾼 꿈을 **서양의 타로카드**와 **동양의 오욕칠정** 개념을 기반으로 해석하고, 앞으로 나아갈 방향을 제시해주는 서비스입니다.

## 2. 왜 만드는가

타로를 봐주는 서비스는 이미 많지만, **타로를 '꿈'과 연결해 해석해주는 서비스는 드뭅니다.**
몽중다로는 이 빈 자리를 노립니다 — 매일 밤 누구나 꾸는 꿈을, 타로와 오욕칠정이라는 두 개의 렌즈로 풀어내 "그래서 지금 나에게 무슨 의미인지"를 알려줍니다.

## 3. 타깃 사용자

- **주 타깃:** 10~30대 여성
- **확장 타깃:** 사주, 오늘의 운세, MBTI, 심리테스트 등 자기 탐색 콘텐츠에 관심이 많은 사람

## 4. 핵심 컨셉

### 4-1. 페르소나 & 어투

몽중다로의 화자는 **꿈을 풀어주는 따뜻한 역술가**입니다.

- **어투:** 타깃층이 읽기 편하고 쉬운 말을 쓰되, **어미만 `~하오`, `~하시오`** 체로 맺어 특유의 분위기를 냅니다. (옛 말투로 어렵게 쓰지 않습니다.)
- **애티튜드:** 꿈 해몽을 들으러 온 사용자를 따뜻하게 바라보며, 잘 되기를 — 오늘 밤 좋은 꿈을 꾸기를 — 기도해주는 마음.
- **나쁜 패가 나왔을 때:** 억지로 좋은 뜻으로 포장하지 않습니다. 다만 **불필요하게 겁을 주지 않고**, 좋은 방향으로 풀어나갈 수 있는 **구체적인 제안**을 건넵니다.

> 📌 이 페르소나는 기존 `philosophy.md`(16세기 조선 역술가·"추상같은 엄격함")에서 **방향을 전환한 것**입니다. 자세한 톤 가이드는 이 섹션을 기준으로 `philosophy.md`를 다시 작성합니다. ([10. 다음 작업](#10-다음-작업) 참고)

### 4-2. 해석의 두 축

- **타로 (서양):** 뽑힌 카드로 꿈의 상징과 서사를 읽습니다.
- **오욕칠정 (동양):** 사용자의 무의식에 지금 어떤 욕구·감정이 얼마나 작용하는지를 수치로 보여줍니다.
  - ⚠️ 수치 체계(항목 수·점수 범위)는 아직 미확정입니다. ([TBD](#tbd-정해야-할-것들) 참고)

## 5. 핵심 기능

### ✅ 1.0 범위 (이번 버전에서 집중)

**① 꿈 해몽**
- 입력: 사용자가 작성한 **꿈 내용**(textarea) + 선택한 **최근의 상태**(8개 중 최대 3개)
- 카드: **랜덤 타로 2장 + 꿈 내용과 관련 있는 타로 1장** = 총 3장
- 출력:
  - 위 입력과 3장의 카드를 기반으로 한 타로 해석
  - **오욕칠정이 각각 얼마나 영향을 주고 있는지 퍼센테이지(%)로 표시**

**② 결과 카카오톡 공유하기**
- 해몽 결과를 카톡으로 공유

> 🔒 **1.0은 위 두 기능까지만 집중합니다.** 아래 기능은 이번 버전 범위 밖입니다.

## 8. 기술 구성 (요약)

- **구조:** pnpm 모노레포 (`apps/client` + `apps/server`)
- **Client (FE):** React 19 + TypeScript + Vite 8 — **담당: 나(FE)**
- **Server (BE):** Fastify 5 + TypeScript — **담당: 별도 BE 담당자**
- **연동:** 개발 환경에서 client `/api/...` → server(`localhost:3000`) 프록시 (CORS 없음)

> 상세 구현/실행 방법은 추후 `README.md`에, API 계약은 `api-spec.md`에 정리합니다.
