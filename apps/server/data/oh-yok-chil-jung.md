# 오욕칠정 (五慾七情) 정의 및 분석 가이드

이 문서는 사용자의 무의식 속에 숨겨진 본능적 욕구(오욕)와 심리적 감정(칠정)을 분석하기 위한 기준입니다.

## 1. 오욕 (五欲): 다섯 가지 본능적 욕망
육체적이고 세속적인 욕구의 상태를 1~10점 사이로 측정합니다.

| 항목 | 의미 | 분석 포인트 |
| :--- | :--- | :--- |
| **식욕 (食欲)** | 음식을 먹고 마시고 싶은 욕구 | 결핍, 보상 심리, 생존 본능 |
| **재욕 (財欲)** | 재물과 물질적인 풍요를 탐하는 욕구 | 불안, 소유욕, 경제적 스트레스 |
| **색욕 (色欲)** | 시각적 즐거움과 이성적 끌림의 욕구 | 미적 추구, 애정 결핍, 감각적 쾌락 |
| **명예욕 (名譽欲)** | 남에게 인정받고 이름을 떨치고 싶은 욕구 | 사회적 자아, 자존감, 인정 욕구 |
| **수면욕 (睡眠欲)** | 잠을 자고 쉬고 싶은 휴식의 욕구 | 번아웃, 회피 심리, 에너지 고갈 |

## 2. 칠정 (七情): 일곱 가지 마음의 감정
상황에 따라 일어나는 마음의 변화를 1~10점 사이로 측정합니다.

| 항목 | 의미 | 분석 포인트 |
| :--- | :--- | :--- |
| **희 (喜)** | 기쁨: 일이 뜻대로 되어 즐거운 마음 | 정신적 충족감, 성취 |
| **노 (怒)** | 노여움: 불만족스럽거나 화가 나는 마음 | 저항심, 억눌린 분노 |
| **애 (哀)** | 슬픔: 상실감이나 서러움을 느끼는 마음 | 과거에 대한 미련, 결핍 |
| **구 (懼)** | 두려움: 불안하거나 무서워하는 마음 | 미래에 대한 불안, 위축 |
| **애 (愛)** | 사랑: 무언가를 아끼고 좋아하는 마음 | 집착, 헌신, 긍정적 연결 |
| **오 (惡)** | 미움: 싫어하고 혐오하는 마음 | 거부 반응, 부정적 에너지 |
| **욕 (欲)** | 욕망: 무언가를 바라는 의욕과 탐욕 | 의지, 목표 의식, 갈구 |

---
*참고: 분석 시 1점은 거의 느껴지지 않는 상태, 10점은 매우 강력하게 지배하고 있는 상태를 의미합니다.*
